## Reproduce the isolated session

1. Use installed Node `24.17.0`, Corepack pnpm `9.15.4` and the source revision above. Build production with developer functions disabled:

   ```sh
   PATH=[REDACTED_HOME]/.nvm/versions/node/v24.17.0/bin:$PATH VITE_DEV_FEATURES=false corepack pnpm build
   ```

2. Create an empty temporary directory outside the repository. Launch from that directory so `loadLocalEnv` cannot discover the repository `.env`. The successful session used `/tmp/storymapper-board-baseline-unrue6`, one origin `http://127.0.0.1:4326`, and a fresh SQLite file in `baseline.lsm`:

   ```sh
   PATH=[REDACTED_HOME]/.nvm/versions/node/v24.17.0/bin:$PATH HOST=127.0.0.1 PORT=4326 LOG_LEVEL=error STORYMAPPER_DB_PATH=/tmp/storymapper-board-baseline-unrue6/baseline.lsm/storymapper.sqlite [REDACTED_HOME]/Projects/StoryMapper/apps/server/node_modules/.bin/tsx --tsconfig [REDACTED_HOME]/Projects/StoryMapper/apps/server/tsconfig.json [REDACTED_HOME]/Projects/StoryMapper/apps/server/src/main.ts
   ```

   Run that command with the temporary directory as the working directory. Without the explicit tsconfig, this outside-repository launch cannot resolve the server aliases; this is setup evidence, not a board defect. Native SQLite and production assets loaded with Node 24. No authentication, GitHub sync or connector enablement was performed.

3. Open a dedicated Chrome tab on that origin; the fresh Project list shows Demo Local Project and PRD to Delivery Map. Open the sample. Record the newly generated Project/Story Map IDs; they change between runs. All route suffixes below apply to `/projects/<projectId>/story-maps/<storyMapId>`, except project-level routes explicitly named below. Browser session date was 2026-10-04 Europe/Madrid; entity timestamps cross the 2026-10-03 UTC boundary.
4. Use the existing sample plus disposable Cards whose titles are the scoped FR identifiers. The observed sample had LSM-1 Activity, LSM-2 Step, LSM-3 Story and MVP. New Activity FR-8, Step FR-9 and Story FR-15 received LSM-4/5/6. No user Project or local-projects directory was opened.
5. After checks, close the owned tab, interrupt only the owned server and remove only the owned temporary directory. Final cleanup and serial gates are recorded in the verification section.

## Clause evidence

### FR-8 and FR-9: creation, editing and movement

- Activity: click New activity, type FR-8, Enter. Step: click New step for FR-8, type FR-9, Enter. Story: click New story for FR-9 in MVP, type FR-15, Enter. Each saves and increases the match count; titles open the detail modal. Activity/Step/Story text labels are visible regardless of color. Editing was exercised extensively on the Story; Activity/Step modals were opened. Independent edit/save at every level was not operated.
- The inline path uses Add activation, text entry and Enter submission. If text entry is counted separately, these are three interactions, so the two-interaction clause is not proven. The aggregate is Partial independently because no Note creation surface exists. Central role names resolve through `card-taxonomy.ts` to `storyMapStrings.cardLevels`; no duplicate role definition was introduced.
- Clicking Move FR-8 left changed its position from 1 to 0 and shifted the original Activity to 1, confirmed in Tree and read-only snapshot. Direct Audit later listed `card.moved`. The existing move operation performs sibling reindexing; this source/API evidence does not prove every drag target.
- Clicking Move FR-15 opens only Unscheduled/Not assigned/Cancel; Unscheduled preserves the Step and clears Release. Tree and snapshot show the cleared Release. Bulk assignment later restores MVP. Modal Release is an assignment form, but the detail modal has no parent or position inputs.
- Pointer drag from the FR-8 grip onto the original Activity tile announced a drop over a raw card ID and left positions unchanged. The Discovery handler accepts `activity:<id>` for that operation; this exact attempt is recorded, without claiming every drag is broken. Space/Right/Space on the Activity grip announced a same-Activity drop and did not move it. Complete keyboard reorder/reparent/Release assignment and all Story/Step drag targets remain unverified; missing equivalent forms are a demonstrated gap owned by 6.3.
